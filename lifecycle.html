App Lifecycle

From prompt to running app to modification to deletion

Creation

  1. User describes an app: "Make me a workout tracker with exercise history"
  2. AI System Service interprets the request
  3. If ambiguous, AI asks one clarifying question (not twenty)
  4. AI generates a complete HTML/CSS/JS app with manifest
  5. OS performs static security analysis (deny-listed patterns, CSP check)
  6. OS presents capability summary: "This app needs: storage, notifications"
  7. User approves
  8. App is packaged as a TWA and installed
  9. App appears in gallery, can be pinned to home

Modification

  1. User says "Add a chart showing weekly progress"
  2. AI receives current app code + modification request
  3. AI generates updated version
  4. OS checks for new capability requirements
  5. If new permissions needed: user approves
  6. Previous version saved to history
  7. App updates in-place, user data preserved

Version History & Rollback

  • Every version is automatically preserved
  • User can rollback to any previous version instantly
  • Rollback restores code, preserves user data
  • If rollback removes capabilities, those are revoked immediately

Error & Crash Handling

  • If a generated app crashes, the OS catches the error and shows a recovery UI
  • User can: retry, rollback to previous version, or ask AI to fix
  • "Fix this app — it crashes when I add an item" triggers a modification cycle
  • Crash data is logged but never sent externally without consent

Deletion

  • User can export all data before deletion (JSON)
  • App code and sandboxed storage are removed
  • Storage is cryptographically wiped
  • Audit log entry preserved (configurable retention)

Generation Failure

  • If the AI fails to generate (network error, token limit): clear error message, suggest retry
  • If generated code fails static analysis: AI is asked to regenerate with constraints
  • If generation cost exceeds budget: user is warned before proceeding
  • Offline: "This request needs cloud AI. Connect to generate, or try a simpler request."
