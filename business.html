Business & Market

How to enter a market owned by two companies

Founder's Existing Assets

The founder operates multiple web app platforms: FreeAppStore, ProAppStore, FreeGameStore, and others. This gives the project existing infrastructure for web app publishing, templates, and distribution -- plus domain expertise in the web app ecosystem. See Founding Story for details.

Product Wedge vs End-State

End-state: A mass-market phone/tablet OS competitor to iOS and Android.

First wedge: A developer/enthusiast-grade flashable OS whose AI-generated app experience is compelling enough to build a user/developer movement.

Parallel validation: AI app generation on the existing FreeAppStore platform tests the core thesis ("describe it, get it") while the OS builds. See Build Phases.

First User Segments

  • AI-first technologists — want to live on the frontier
  • Privacy/control power users — already flash GrapheneOS/CalyxOS, willing to trade convenience for control
  • Entrepreneurs — want custom personal tools without hiring developers
  • Developer communities — experimenting with new app models
  • Organizations (later) — controlled purpose-built tablet/phone workflows

These aren't the mainstream market. They're groups that tolerate early-platform trade-offs and prove the interaction model.

Developer Proposition

Developers can:

  • Build standard TWAs with HTML/CSS/TypeScript
  • Access system capabilities through documented permissioned APIs
  • Let AI generate scaffolding and UI
  • Publish apps or templates to a marketplace
  • Build reusable tools the OS AI can safely invoke
  • Target phones and tablets from one responsive app

Defensibility

Access to an LLM is not defensible — every platform has one. Potential defensible assets:

  • The trusted TWA runtime and capability broker architecture
  • Permission and audit system as a trust brand
  • Accumulated user workflows and personal app libraries
  • Developer/template/tool ecosystem
  • Hardware/software integration on reference devices
  • Distribution partnerships
