GrapheneOS — Our Base Distribution

What it is, what it ships, how we build on top of it

What Is GrapheneOS

GrapheneOS is an independent, privacy-focused mobile OS based on AOSP. It targets Pixel phones exclusively. Key facts:

  • Maintained by a small team led by Daniel Micay since 2014 (originally CopperheadOS)
  • Supports Pixel 4 through Pixel 9 series
  • Ships without Google apps or services
  • Adds significant security hardening on top of AOSP
  • Monthly security patches merged from AOSP
  • Used by journalists, activists, security professionals

Why GrapheneOS Over Stock AOSP

FeatureWe get for free
Vanadium (hardened Chromium)Our entire TWA runtime, pre-built and maintained. We'd have to build our own Chromium fork otherwise.
Hardened memory allocatorProtection against heap exploits in system services. Relevant because we run untrusted AI-generated code.
Hardened kernel (MTE, CFI)Memory tagging and control flow integrity. Extra defense layer around the Capability Broker.
Per-app network permissionGenerated TWAs can be denied network access per-app. Aligns with our "local-only by default" policy.
Per-app sensor permissionGenerated TWAs can be denied sensor access. Maps to our Tier 1 permission model.
No Google servicesExactly what we want. No GMS, no Play Services, no Firebase, no tracking.
Pixel 8 device treeMaintained and tested monthly. We don't touch device bring-up at all.
Security patchesMonthly AOSP security patches merged by the GrapheneOS team, not by us.
Verified boot with own keysWe can sign our OS with our own keys. Not dependent on Google's signing.
OTA update infrastructureExisting update server architecture we can adapt.

The Minimal Diff

Our entire change from stock GrapheneOS is:

# overlay/device_aiphone.mk (5 lines)
PRODUCT_PACKAGES += AIPhoneHome
PRODUCT_PACKAGES += -Launcher3 -Calculator -Calendar -DeskClock -Gallery2 -Files
PRODUCT_SYSTEM_PROPERTIES += ro.aiphone.version=0.1.0

# overlay/packages/apps/AIPhoneHome/ (3 files)
HomeActivity.java    — 50 lines, one WebView
AndroidManifest.xml  — HOME intent filter
index.html           — AI chat UI, plain HTML/JS

That's it. Three files and a five-line build config. Everything else is GrapheneOS unchanged.
