Capability Tiers

Five levels of system access, from automatic to kernel-adjacent

Tier 0 — Automatic no approval

Granted at install. No user prompt needed.

  • storage — Sandboxed encrypted per-app key-value + SQLite
  • haptics — Vibration feedback
  • navigation — Close app, go home
  • UI rendering: Canvas, WebGL, WebGPU
  • Service Workers for offline operation

Tier 1 — Standard one-time approval

Prompted once, remembered until revoked.

  • camera — Photo/video capture, photo picker, live stream
  • microphone — Record, stream, speech-to-text
  • location — GPS, watch, geocoding, reverse geocoding
  • notifications — Local push, scheduled, actionable
  • files — File picker (import/export)
  • clipboard — Read/write
  • share — Native share sheet
  • sensors — Accelerometer, gyroscope, barometer, proximity, light, step counter
  • ai — Ask the OS LLM, classify, summarize, extract, vision, embeddings

Tier 2 — Elevated explicit approval + explanation

User sees what the app will access and why.

  • filesystem — Full read/write/watch directories
  • contacts — Read, create, update, delete
  • calendar — Events CRUD
  • bluetooth — Scan, connect, peripheral mode
  • nfc — Read/write NFC tags
  • usb — USB host mode, connect devices
  • network — Raw TCP/UDP sockets, unrestricted HTTP
  • background — Persistent background tasks with scheduling
  • audio — Output routing, volume control
  • ipc — Inter-app communication through OS broker

Tier 3 — Privileged audit + visible indicator

Prompted every time OR visible system indicator while active.

  • telephony — Make calls, send SMS (confirmation UI always shown)
  • system — Brightness, orientation, wake lock, battery/network info
  • device-admin — Enterprise policies
  • vpn — VPN configuration
  • network-filter — eBPF-based filtering
  • input-method — Custom keyboards, gesture systems
  • accessibility — Accessibility services
  • screen-capture — Screenshot/recording

Tier 4 — Kernel-Adjacent phase 3+

Extreme power. Defined after the security model is proven in production.

  • fuse — User-space filesystems (encrypted vaults, network drives)
  • ebpf — Custom tracing and network filtering programs
  • scheduling — Process priority hints
  • drivers — User-space device I/O
  • audio-dsp — DSP access for audio processing

Never Exposed to TWAs

  • Secure boot / verified boot modification
  • SELinux policy changes
  • Kernel module loading
  • Encryption key management
  • OTA update mechanism
  • Baseband/radio firmware
