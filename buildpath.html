Build Path & Phases

From architecture to commercial product

Phase 0a — Architecture & Decisions done

  • Product constitution: OS, not launcher, not an app
  • Trust/security specification and TWA package model
  • Foundation decision: AOSP Minimal (researched Halium, postmarketOS, others)
  • Runtime decision: Chromium Content Shell (researched V8, WebKit, Servo)
  • No native apps, no frameworks, plain HTML/JS

Phase 0b — Demand Validation this week

  • "Create App" button on FreeAppStore -- AI generates web apps from prompts
  • Watch what people type, what they do with generated apps
  • Runs in parallel with Phase 1 -- validates the thesis while the OS builds

Phase 1 — AOSP Minimal Boot this month

  • AOSP Minimal build booting on emulator, then Pixel 8
  • Stock apps stripped, custom AI home screen as only visible UI
  • WebView runtime with plain HTML/JS interface
  • Capability Broker with Tier 0-1 APIs
  • AI app generation flow (cloud)
  • Permission manifest and audit-log UI

Phase 2 — Flashable Pixel 8 Build

  • OS image boots on Pixel 8
  • Networking, display, input, storage, notifications working
  • Tier 2 capabilities: Bluetooth, filesystem, contacts, calendar
  • Phone app (dialer, SMS) as TWA
  • Camera integration
  • Phone + tablet adaptive UX

Phase 3 — Alpha

  • 5 killer generated apps demonstrating deep capabilities
  • Local AI model on Tensor G3 TPU
  • Tier 3 capabilities
  • Voice input (local Whisper)
  • Offline app execution and local intent routing
  • Small invited user cohort

Phase 4 — Developer Platform

  • TWA SDK and developer tools
  • App manifest/capability documentation
  • Package signing and update path
  • Security review and disclosure process
  • First public developer build
  • App/template marketplace

Phase 5 — Commercialization

  • Partner hardware vs own reference device decision
  • OTA policy and device support lifecycle
  • Carrier/regulatory/emergency readiness
  • Business model selection
  • Distribution strategy
