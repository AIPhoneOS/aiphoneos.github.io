Model Comparison

Every model that fits on Pixel 8, ranked for our use case

The Constraint

Pixel 8 has 8GB RAM. The OS + framework + WebView uses ~4GB. That leaves ~4GB for models. All sizes below are Q4_K_M quantization (4-bit, ~95% of full quality).

OS + Framework (~4GB)Available for models (~4GB)

Intent Routing Models (always loaded)

The intent router classifies every user input. Must be tiny, fast, always in memory.

Gemma 3 1B

chosen
Size~720 MBSpeed (GPU)~35-50 t/s
Params1.0BLatency~200ms
LicenseApache 2.0FromGoogle

Tiny, fast, good at classification. "Is this create/modify/query/action?" — that's all it needs to do. 720MB leaves 3.3GB for the generation model. Apache license means no restrictions.

SmolLM 2 360M

alternative
Size~250 MBSpeed (GPU)~60-80 t/s
Params360MLatency~100ms
LicenseApache 2.0FromHugging Face

Even smaller. If Gemma 1B is overkill for classification, this saves 470MB of RAM. May need fine-tuning for our specific intent categories.

App Generation Models (loaded on demand)

Generates HTML/CSS/JS from prompts. Loaded when user creates/modifies an app, unloaded after. Code quality is critical.

Phi-4 Mini 3.8B

chosen
Size~2.5 GBSpeed (GPU)~15-25 t/s
Params3.8BGen time~15-25 sec
LicenseMITFromMicrosoft

Smartest sub-4B model in 2026. Outperforms Gemma 3 4B and Llama 3.2 3B on chain-of-thought and code tasks. MIT license. Strong at structured output (HTML generation). The best we can fit.

Gemma 3 4B

alternative
Size~2.9 GBSpeed (GPU)~10-18 t/s
Params4.0BGen time~20-30 sec
LicenseGemma licenseFromGoogle

Slightly larger, slightly slower. Good at code but Phi-4 Mini beats it on reasoning benchmarks at smaller size. Gemma license has some restrictions (no competing with Google services).

Llama 3.2 3B

alternative
Size~2.1 GBSpeed (GPU)~15-22 t/s
Params3.0BGen time~12-20 sec
LicenseLlama 3.2FromMeta

Smaller and faster but less capable at code generation. Good instruction following. Llama license has usage restrictions above 700M monthly active users (not our concern yet).

Qwen 2.5 3B

alternative
Size~2.0 GBSpeed (GPU)~15-22 t/s
Params3.0BGen time~12-20 sec
LicenseApache 2.0FromAlibaba

Best multilingual option. If we need the OS to generate apps in non-English languages, Qwen is the choice. Apache license, no restrictions. Code quality slightly below Phi-4 Mini.

Cloud is used when: (1) app is too complex for Phi-4 Mini, (2) user explicitly requests higher quality, (3) device is thermal-throttled, (4) local generation fails validation.

Why Not Bigger Models?

ModelSize (Q4)Why not
Llama 3.2 7B~4.5 GBDoesn't fit alongside the OS in 8GB RAM
Mistral 7B~4.5 GBSame — too large for 8GB device
Phi-4 14B~9 GBWay too large. Needs 16GB+ device.
Gemma 3 12B~8 GBWould require the entire device RAM.

The 4GB available RAM ceiling is hard. Pixel 9 Pro (16GB) could run 7B models. Future hardware expansion is a path to better local generation.

Decision Summary

Intent Router: Gemma 3 1B (720MB, always loaded, ~200ms response)
App Generator: Phi-4 Mini 3.8B (2.5GB, loaded on demand, ~15-25 sec)
Cloud Fallback: Claude Sonnet (complex apps), Claude Haiku (simple queries)
Runtime: LiteRT-LM (C++ core, Java API, Apache 2.0). Decision rationale
Compute: OpenCL GPU (primary, 52 t/s) + NPU/TPU (secondary). CPU reserved for UI only.
