Trusted Web Apps (TWA)

The only app format on AIPhone OS

A TWA is a first-class OS citizen built with web technologies. It gets deeper system access than any browser PWA — and deeper than most native apps on iOS/Android can achieve.

Package Structure

myapp.twa/
  manifest.json        # Identity, capabilities, metadata
  index.html           # Entry point
  *.js, *.css, *.html  # Application code
  assets/              # Images, fonts, etc.
  signature.json       # OS-generated package signature
  history/             # Version history (auto-managed)
    v1.bundle
    v2.bundle

Manifest

{
  "twa_version": "0.2",
  "id": "user.expense-tracker",
  "name": "Expense Tracker",
  "description": "Track daily expenses with receipt photos",
  "icon": "emoji:receipt",
  "version": 1,
  "created_by": "ai-generated",
  "created_at": "2026-05-23T14:00:00Z",
  "origin_prompt": "Make me an expense tracker with receipt photos",
  "capabilities": {
    "required": ["storage", "camera"],
    "optional": ["notifications", "share", "ai"]
  },
  "storage": { "quota_mb": 50, "encryption": "os-managed" },
  "network": { "policy": "local-only", "allowed_hosts": [] },
  "background": { "allowed": false },
  "data_export": { "format": "json", "user_deletable": true }
}

RollbackNoInstant version rollback

Killer Demo Apps

Three apps that prove the concept:

1. Personal Tracker

"Make me a weekly spending tracker with receipt photo upload." Uses: storage, camera, notifications, AI (receipt OCR). Proves personal app generation.

2. Connected Dashboard

"Show my calendar events, outstanding tasks, and weather." Uses: calendar, storage, network, IPC. Proves cross-app data orchestration.

3. Hardware Capability App

"Create a Bluetooth device scanner with signal strength logging." Uses: bluetooth, storage, background. Proves deep hardware access no browser allows.
