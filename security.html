Security Model

The trust model for AI-generated code

The product generates code and connects it to sensitive phone capabilities. If this trust model fails, the product fails regardless of usability.

Core Principle

Generated code is always untrusted. Even though the OS's own AI produced it. AI-generated code can be insecure, incorrect, or malicious. The platform assumes the worst and enforces boundaries deterministically.

Nine Defense Layers

See also: Capability Tiers for the 5-level permission model, and Broker API for the code-level interface.

LayerWhat It Does
1. Process IsolationEach TWA runs in its own sandboxed process
2. Capability BrokerAll system access mediated and enforced by OS code, not app code
3. Static AnalysisCode scanned for dangerous patterns before installation
4. CSP EnforcementNo eval(), no external script loading, strict content policy
5. Network PolicyDefault local-only; explicit allowlist for external network
6. Permission System5-tier approval model, revocable at any time
7. Audit LogEvery privileged action recorded with timestamp and context
8. Version HistoryInstant rollback to any previous version
9. Data SovereigntyAll data on-device by default, user controls export/deletion

Static Analysis Rules

  • eval() — blocked
  • new Function() — blocked
  • Dynamic <script src="..."> from external URLs — blocked
  • document.write() — blocked
  • Fetch/XHR to non-allowlisted hosts — blocked by network policy
  • Capability API calls not declared in manifest — flagged, blocked
  • Bundle size exceeding limit — rejected

Generated Code Policy

The OS never trusts code merely because its own AI produced it. Every generated app gets:

  • The same sandbox as any third-party app
  • The same capability enforcement
  • The same audit logging
  • No elevated privileges based on origin

Data Sovereignty

  • All user data on-device by default. No cloud sync unless explicitly opted in per-app.
  • User can export all data from any app as JSON at any time.
  • User can delete all data from any app instantly.
  • Deleted data is cryptographically wiped, not just unlinked.
  • Cloud AI queries are transient — no conversation history stored server-side.
  • The OS never sends personal data to train AI models.
