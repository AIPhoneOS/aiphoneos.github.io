Key Design Principles

  • AI proposes, system enforces. The LLM is the orchestration layer, not the security layer.
  • Web apps are the only app format. No Android APKs. Every app is a TWA.
  • Deep access, strict mediation. Web apps get kernel-level capabilities, all through the Capability Broker.
  • System apps eat their own cooking. Phone, Settings, Home are all TWAs.
  • Transparency is a feature. Every privileged action is logged and visible to the user.
